⏰ 相对论：两惯性系中时钟相遇 | 时刻相同条件

Σ 和 Σ' 沿 x 轴相对运动，速度 v。原点相遇时 t = t' = 0。
Σ 系中某点 (x, y, z) 处的时钟与 Σ' 系中何处的时钟相遇时，指示的时刻相同？

相遇点满足：x' = -γ·x，且 t' = t = γ·(x/v)·(1 - 1/γ)

📐 相对论计算过程

❶ 设 Σ 系时钟位于 (x, 0, 0)，读数 t
该时钟的世界线：x = 常数，时间从 0 到 t
❷ 洛伦兹变换到 Σ' 系
x' = γ(x - vt)，t' = γ(t - vx/c²)
其中 γ = 1/√(1-β²)，β=v/c
❸ 相遇时两时钟读数相同
Σ' 系中相遇点的时钟读数等于 t'，要求 t' = t
→ γ(t - vx/c²) = t → t(γ-1) = γ·vx/c²
❹ 求解相遇条件
t = (γ·vx/c²)/(γ-1) = (x/v)·(1 + 1/γ)
且 x' = γ(x - vt) = -γ·x/(γ+1) = -x·(γ/(γ+1))
🎯 相遇时读数相同条件
t = t' = 0.00 × (x/v)
Σ' 系中相遇位置: x' = 0.00 · x
