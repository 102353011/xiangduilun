📐 相对论长度收缩 | 平行尺反向运动

两把固有长度 l0 的尺子，相对于实验室参考系以相同速率 v 沿相反方向运动。
观测视角：站在红色尺上测量蓝色尺的长度

l = l0 · (1 - β²) / (1 + β²)    (β = v/c)

📐 相对论计算过程

❶ 实验室系参数
β = v / c = 0.500
❷ 相对速度合成 (洛伦兹变换)
u = (v + v) / (1 + v²/c²) = 2v / (1 + β²)
⇒ u/c = 0.800
❸ 长度收缩因子推导
γrel = 1/√(1 - u²/c²)  →  收缩因子 = √(1 - u²/c²)
代入化简得：(1 - β²)/(1 + β²)
❹ 观测长度结果
l = l0 × (1 - β²)/(1 + β²)
📏 预测观测长度 (蓝尺收缩后)
l = 1.200   (l0 = 2.00)
蓝色尺视觉长度 = 此值，实时动态收缩
