📐 电偶极辐射为零

在质心系中，x₂ = -x₁，因此电偶极矩 p = q(x₁ + x₂) = 0。这是严格恒等式，与运动状态无关。电偶极辐射功率 P ∝ |p̈|² = 0。

🧲 磁偶极辐射为零

利用对称性得 m = q(x₁ × v₁)。中心力场中力矩为零，角动量守恒，故 m 为常矢量。磁偶极辐射功率 P ∝ |m̈|² = 0。

🧪 对称性破缺

若电荷相反（q, -q），则 p = q(x₁ - x₂) = 2qx₁ ≠ 0。若质量不同，质心偏离，对称性破缺，辐射将产生。

📖 完整解题过程（教材标准解答）

题目 5.6：两个质量、电荷都相等的粒子相向而行发生碰撞，证明电偶极辐射和磁偶极辐射都不会发生。

步骤一：分析系统对称性

设两个粒子的质量均为 m，电荷均为 q（同号电荷）。

由于两粒子相向碰撞且质量 m 相等，因此系统的总动量为零：

mv1 + mv2 = 0

由此可知，在质心系中两个粒子的运动速度和位置矢量等值反向：

v1 = -v2 ,    x1 = -x2
物理意义：两个全同粒子关于质心成镜像对称。质心坐标系是分析此问题的最佳参考系，因为系统的总动量始终为零。

步骤二：证明电偶极矩为零

电偶极矩的定义：

p = Σi=12 qixi = qx1 + qx2

代入对称性条件 x₂ = -x₁：

p = qx1 + q(-x1) = q(x1 - x1) = 0

电偶极辐射功率（Larmor公式）：

P电偶极 = (2/3c³) |p̈|2 = (2/3c³) |d²(0)/dt²|2 = 0
✅ 电偶极辐射严格为零！这是由系统的空间反演对称性决定的恒等式。
关键理解：无论粒子如何运动（加速、碰撞、散射），只要质心系条件 x₂ = -x₁ 成立，电偶极矩 p 就始终为零。这不是近似结果，而是严格恒等。

步骤三：证明磁偶极辐射为零

磁偶极矩的定义：

m = (1/2) Σi=12 xi × qivi = (1/2)[x1 × qv1 + x2 × qv2]

代入对称性条件 x₂ = -x₁，v₂ = -v₁：

x2 × v2 = (-x1) × (-v1) = x1 × v1
m = (q/2)[(x1 × v1) + (x1 × v1)] = q(x1 × v1)
注意：对于一般的非对心碰撞（b ≠ 0），m = q(x₁ × v₁) ≠ 0。此时磁偶极辐射为零的原因是 m 为常矢量（角动量守恒），而非 m = 0。

角动量守恒证明：

粒子1受到的库仑力沿两粒子连线方向（中心力场）：

F1 ∝ (x2 - x1) = -2x1

力矩（对质心）：

τ = x1 × F1 ∝ x1 × x1 = 0
d(x1 × v1)/dt = 0  →  x1 × v1 = 常矢量

磁偶极辐射功率：

P磁偶极 = (2/3c³) |m̈|2 = (2/3c³) |d²(常数)/dt²|2 = 0

对心碰撞的特殊情况（b = 0）：

当碰撞参数 b = 0 时，x1 与 v1 共线，因此：

x1 × v1 = 0  →  m = q · 0 = 0
✅ 磁偶极辐射严格为零！对于对心碰撞，m = 0；对于非对心碰撞，m = 常数。两种情况均无辐射。

步骤四：总结与结论

电偶极辐射为零：由空间反演对称性（x₂ = -x₁）直接导致 p ≡ 0。

磁偶极辐射为零：由角动量守恒（中心力场力矩为零）导致 m = 常数，故 m̈ = 0。

核心物理图像：

电偶极矩 p = q(x1 + x2) = q · 0 = 0
磁偶极矩（对心） m = q(x1 × v1) = q · 0 = 0
磁偶极矩（非对心） m = q(x1 × v1) = 常数 ≠ 0，但 m̈ = 0
✅ 证毕：两个质量、电荷都相等的粒子相向碰撞时，电偶极辐射和磁偶极辐射都不会发生。
